# WhatsApp Warmup Service

Сервис для прогрева WhatsApp-аккаунтов через Telegram-бота, с PostgreSQL/Neon, Baileys и Telegraf.

## Основные возможности

- Подключение WhatsApp по коду 8 или QR
- Список аккаунтов с возможностью удаления
- Ограничение: до 10 номеров на пользователя
- Проверка активности каждые 10 минут
- Реферальная система: 5% от выплат приглашённых пользователей
- Админ-панель: статистика, список пользователей, рассылка
- Выбор режима прогрева: 1 к 1 или 1 ко всем
- Длительность прогрева: 6 или 12 часов
- Настройка задержки между сообщениями: 20-250 секунд
- Формат номера: `+7XXXXXXXXXX`, `8XXXXXXXXXX`, `9XXXXXXXXX`

## Стек

- Node.js 20+
- TypeScript
- Telegraf
- Baileys / WhiskeySockets
- PostgreSQL / Neon

## Установка

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

3. Заполните значения для Telegram и PostgreSQL.

4. Запустите dev-режим:

```bash
npm run dev
```

5. Для продакшена:

```bash
npm run build
npm start
```

## Render.com

Файл `render.yaml` готов для деплоя. Укажите `TELEGRAM_BOT_TOKEN`, `BOT_USERNAME`, `DATABASE_URL` в переменных окружения Render.

## Docker

```bash
docker build -t whatsapp-warmup-service .
docker run --rm -p 3000:3000 --env-file .env whatsapp-warmup-service
```

Или через compose:

```bash
docker compose up --build
```

## Реалистичная доводка для WhatsApp-автоматизации

Для реального продакшн-режима важно:

- использовать отдельную PostgreSQL БД и хранить session-данные в защищённом месте;
- ограничивать число одновременно подключённых аккаунтов;
- создавать мягкий тайминг прогрева, иначе Meta может пометить аккаунты как подозрительные;
- держать отдельный health-check и логирование на каждый аккаунт;
- обязательно хранить `session_key`/сессии в безопасном контейнере/томе, а не в временных файлах;
- использовать `requestPairingCode`/QR только после явного подтверждения пользователем;
- делать проверку активности через расписание и закрывать сессии после таймера.

## Структура

- `src/bot` — Telegram-бот и клавиатуры
- `src/db` — схема PostgreSQL и API работы с БД
- `src/services` — Baileys и логика прогрева
- `src/index.ts` — точка входа

## Важное замечание

WhatsApp-автоматизация может быть ограничена политикой Meta. Данный проект является технической заготовкой/каркасом для внутренних тестов и администрирования с умеренным прогревом, но не гарантирует отсутствие блокировок.
